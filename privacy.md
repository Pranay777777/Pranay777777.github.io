# JobOS Privacy Policy

Last updated: 5 October 2026

JobOS is a personal tool used only by its owner. This policy explains what Google data it accesses and how that data is handled.

## Who uses JobOS

Only the owner of the JobOS Google Cloud project signs in to JobOS. It does not collect data from any other users.

## Google data JobOS accesses

With the owner's permission, JobOS uses these Google services on the owner's own account:

- **Google Sheets:** to create and update a job-application tracker.
- **Google Drive and Google Docs:** to store and read the owner's resumes and cover letters.
- **Gmail:** to send job-search emails the owner has approved, and to read replies so they can be sorted and followed up.

JobOS does not access any other Google account.

## How data is used and stored

- Data is used only to run the owner's job search.
- Sign-in tokens and working data are stored locally on the owner's computer and are not uploaded to any JobOS server. There is no JobOS server.
- To score job listings and draft messages, some text (such as job descriptions and drafts) may be sent to AI model providers that the owner has chosen. This is done only for the owner's own job search.

## Sharing

JobOS does not sell, rent or share Google user data with anyone, and does not use it for advertising.

JobOS's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

The owner can revoke JobOS's access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions) and delete the locally stored data.
